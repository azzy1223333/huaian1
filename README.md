# 槐安里：未寄出的全家福

> 一款中式怪核 / 千禧年复古网页风格的 ARG 网页游戏。
>
> 1999 年最后一天，槐安里 7 号楼的居民拍了一张“千禧百家福”。
> 照片里有一百个位置，九十九个人。少掉的那个人，不在任何一份名单上。

---

## 如何开始

推荐使用 **Microsoft Edge** 或 **Chrome** 打开。

### 方式一：双击启动脚本（推荐）

双击 `启动游戏.bat`。脚本会优先用本机的 Python 启动一个本地静态服务器，并在浏览器中打开：

`http://127.0.0.1:8765/`

本地服务器可以让浏览器的 `localStorage` 存档稳定工作。关闭那个最小化的服务器窗口即可停止服务。

### 方式二：直接打开

双击 `index.html`，或将它拖进浏览器窗口。

绝大多数 Chromium 浏览器允许 `file://` 页面写入 `localStorage`，但部分浏览器或隐私设置会禁止。如果启动界面提示“本地存档不可用”，请改用方式一。

## 游戏操作

- 点击页面中的链接、照片、附件和按钮进行调查。
- 顶部工具栏的 **后退 / 前进 / 刷新 / 主页** 均可使用。
- 地址栏可以输入站内地址（例如 `404.htm`、`bbs/topic.asp?id=404`、`~xiaoman/last.htm`），也可以直接输入页面路径。
- **线索本**（工具栏或底部链接）可以查看已收集的底片和线索。
- 右上角的 **声音** 和 **特效** 可以随时关闭。
- 游戏自动存档，关闭浏览器后再次打开，可在启动界面选择“继续上次浏览”。

游戏包含闪烁画面、突发音效、压抑措辞与中式恐怖意象。可以在启动界面或工具栏关闭视觉特效和声音。

## 存档

- 存档键：`huai_an_li_save_v1`
- 存储位置：浏览器 `localStorage`
- 自动保存时机：进入新页面、收集底片 / 线索、聊天、解开铁门、选择结局、离开页面等。
- “重新开始”会清除进度，但保留已经发现的结局。
- 结局页与开发者工具中也提供了重置入口。

1. **公告**：在 `/notice` 收取附件“合影底片_099.jpg”，得到底片 1；记录“第 99 户”名单异常。
2. **相册**：打开 `/album` 的第 1 张照片，收取底片 2；打开第 8 张“未命名”照片，收取底片 5（同时得到生日线索）。
3. **BBS**：进入 `/bbs/404`，打开 `DSC_0404.jpg` 附件，得到底片 3。

5. **个人主页**：在 `/diary` 记下生日 `1987-11-07`；如果还没有底片 5，可以在这里展开纸鹤。
6. **隐藏日记**：收集底片 5 后，主页会出现“未寄出的日记”；读完会得到“不要回头”的线索。
7. **OICQ**：找到至少 4 张底片后去 `/chat`。点击“我记得你。”，纸飞机会发来 `地下室台阶.jpg`，得到底片 6。
8. **防空洞**：去 `/bbs/underground` 或直接进入 `/underground`。至少 6 张底片时，输入密码 `1107` 开门。
9. **地下室**：按“向前”推进到第 4 阶段，取下最后一张底片（底片 7）。听见声音后选择“不要回头”，走到出口。
10. **修复**：进入 `/ritual`，开始显影，选择“在名单上写下她的名字”，输入 `沈小满`，进入真结局。

    - 输入自己的名字填进第 100 户 → 坏结局。
    - 选择“关闭网页，删除存档” → 普通结局。
    - 在地下室选择“回头”会触发失败，需要重新走一遍拿最后一张底片，不会永久卡死。

## 技术说明

- 纯静态网页，无构建步骤、无外部请求。
- 页面由 `index.html` + `css/main.css` + `js/content.js` + `js/pages.js` + `js/game.js` 组成。
- 所有照片为本地 SVG 插画，带噪点、划痕、暗角与老照片调色。寻人启事照片、无脸档案照和“未显影底片”占位图均为本地生成图片，不依赖外部图床。
- 环境音由 Web Audio API 实时合成，没有音频文件。
- 使用 Hash 路由（`#/album` 等），可以直接刷新与分享站内页面。
- 开发者工具密码仅用于本地调试，不涉及真实服务器。
